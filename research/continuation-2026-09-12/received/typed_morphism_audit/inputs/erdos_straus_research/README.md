# Marked residual selectors for the Erdős–Straus equation

## Deliverables

`paper.pdf` and `paper.tex` contain the research note and coordinate-level proofs.
`verifier.py` is an executable, standard-library-only verifier. `lean_plan.md`
is a dependency-ordered formalization specification, not a compiled Lean proof.
`sources.json` identifies the primary antecedents actually consulted and their
precise locators. The JSON files in `tables/` retain the channel, residual,
primitive ray, normalization coordinates and raw denominator orientation.

The algebraic results are proved in the note. The finite certificates do not
prove its infinite distributional statements. Conversely, the distributional
statements are not used as premises for the finite computations.

## Reproduce the complete finite computation

Use Python 3.9 or later, without optimization flags (`-O` or `-OO`). No package
installation and no network access are required.

```sh
python3 verifier.py --bound 2000000 --out regenerated_tables --families
```

This regenerates the 4,519-prime hard-class census, the all-residual three-ray
census, the finite 138-ray extension and its four-middle-shell repair, both complete stress tests, every minimal
target pattern, the local CRT checks, map/inverse checks and primality
certificates. Use a fresh output directory. The included `run_log.txt` records
an actual successful run of the full command; runtime is machine-dependent.

For only the small structural tests, isolated sharp examples and pattern tables:

```sh
python3 verifier.py --self-test-only --out regenerated_self_tests
```

A different positive `--bound` changes the main finite prime census but does not
change the isolated certificates. No assertion about primes beyond the specified
bound is made by the census. `--families` performs the additional finite ray
search; it is not required for the three-ray computation.

To compile the source document in a TeX installation containing the packages in
its preamble:

```sh
pdflatex -interaction=nonstopmode -halt-on-error paper.tex
pdflatex -interaction=nonstopmode -halt-on-error paper.tex
```

## Main mathematical results

The prime-incidence product law is an exact limit for every fixed finite set of
auxiliary primes. Negative cross-covariances are asserted in that same limit,
not for the untruncated number of residuals. Simultaneous density-one
multiplicities use two successive limits, not a density-to-pointwise inference.

For the fixed rays (2,1), (3,2), (5,3), every exterior hit can be witnessed by a
residual with respectively at most 2, 3, 5 prime factors counted with
multiplicity. All three bounds are attained at hard primes. The 60-modulus
completion uses finite capacities, not just the subgroup generated by factor
residues. Each target (59 and 11 modulo 60) has exactly 184 minimal patterns.

For any fixed family of k distinct primitive positive rays, its bounded exterior
exceptional set in each fixed hard progression is O(X/(log X)^(1+k/2)). The note
proves the sieve step with a fixed truncation and the residual inequality. The
explicit 138-ray family therefore has exponent 70, with a fixed family-dependent
constant. This is not a numerical error estimate for the 2,000,000 census. The same exponent also holds when only witnesses with Omega(R)<=2 and R<=p^epsilon are allowed, for each fixed epsilon>0. For R<=(log p)^A, for any fixed A>0, a two-cutoff refinement gives exceptional bound O(X/(log X*(log log X)^(k/2))). These are quantitative almost-all statements, not pointwise bounds.

The unimodular companion-basis map classifies all exterior states at fixed p,R,
including signed coordinates and an exact height obstruction. The cubic
factor-swap produces a middle state exactly on R | (4r^3 - 1), and its inverse
fibres retain the square normalization mark. An explicit infinite prime
progression includes the crossing at p=2521.

## Necessary distinctions and nonclaims

* The selector window is 0<R<p, equivalently p/4<a<p/2. Completeness is proved
  for that window; no claim is made that every possible Erdős–Straus solution
  has a denominator in it.
* At p=1201 there are 15 distinct raw oriented states/triples but only 11
  increasing triples. The four middle orientation pairs explain the difference.
  Raw order is never silently replaced by increasing order.
* At p=2521 all three positive states are middle. Its complete exterior slope
  list lies outside the entire stipulated positive chamber. Consequently no
  exterior-only positive family, even an infinite one, covers every hard prime
  in this bounded window.
* The 138-ray exterior census covers 4,508 of 4,519 primes. Positive middle
  states at the four fixed residuals 11,19,23,39 repair its 11 misses, so the
  hybrid family covers all 4,519 primes in the specified finite range. Neither
  this finite result nor the logarithmic-power bound proves universal coverage.
* No global proof of the Erdős–Straus conjecture, untruncated covariance theorem,
  uniform-in-family sieve constant, completed Lean proof, or exhaustive claim
  of priority over the mathematical literature is asserted.

A state has integer fields `p`, `R`, `a`, `u`, `h`, `r`, `s`; `channel` is `E`
or `M`; exactly one of `kappa`, `lambda` is non-null. Both `denominators_raw` and
`denominators_increasing` are retained. `positive_chamber` uses exact integer
inequalities, with no floating-point surd comparison. Some certificates add
explicit transfer marks, such as `transfer_g`; the basic marks remain intact.
Denominators can exceed 2^53. JSON numbers here denote exact integers: use
Python `json` or another arbitrary-precision parser, not a parser that silently
rounds every number to binary64.

`prime_residual_states` counts states, while `prime_residual_prime_hits` counts
primes. `all_residual_*` means prime and composite residuals are both included.
The first common-class witness at 17,929 is new relative to the old prime-only
channels; it was already covered by a composite residual on the second ray.

## Provenance

The exterior congruences are inherited from Yamamoto (1965), Lemma 2, equation
(4), p. 38. The Type I/II coordinate background is Elsholtz–Tao (2013), §2.
The fixed-modulus prime distribution inputs are Rudnick's 2015 notes and
Williams (1974). The inverse-residue half-support mechanism has a direct
antecedent in Dahan (2026), §4.1; the note identifies its adaptation rather than
claiming that mechanism as new. The finite-capacity completion, explicit marked
transfer, inverse fibres and additional obstruction certificates are derived in
this note. The Rosati attribution in the prompt is not represented as a claim
that the original Rosati article was directly consulted.
