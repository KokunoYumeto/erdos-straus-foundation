# Exact Lean-ready dependency plan

This is a formalization specification, not a compiled Lean file. No Lean executable, mathlib revision, transitive-axiom check or independent formal reviewer was used. The inherited plans remain in their original packages. New proofs below must not be replaced by axioms named after the desired conclusions.

## Representations

Use `Fin 24 -> Int` for raw Golay numerators; the Euclidean norm is the rational quadratic form `sum x_i^2 / 8`. Use `Fin 24` with 23 denoting infinity, and a separate `WithTop (ZMod 23)` equivalence. Do not identify those types by coercion. A codeword is a `Finset (Fin 24)` with addition symmetric difference. A trace is a linear functional with an integrality proof. A Wilson state is three vectors `Fin 8 -> Rat` with its own stated half-sum norm. A first-Tits state is three `Matrix (Fin 3) (Fin 3) GaussianRat` values, with typed block arrows and explicit compact-real equations. Keep ES divisor `uES`, Fable source `uF`, and the phase, flag, scale and channel types separate.

The manifest constants are untrusted inputs. Decode into these types, then prove the following finite propositions. A successful external Python execution is not the proof term.

## A. Code and linear symmetry

A05. Check each permutation maps every code-basis word into the code; deduce equality and preservation of the full code.
A06. Define the Leech numerator additive subgroup by common parity, sum congruence and code condition; prove closure, inverse closure and the coordinate-action homomorphism.
A07. Define P, P9 and the first-four-view packing and unpacking; prove the common-sum identity and T^4=C relation.
A08. Check the displayed vector is in the subgroup, P9(v)=0 and P9(Jv)=(0,0,0,-2,-2,2,0,0,2).
A09. Deduce no function Jbar on the P9 quotient can intertwine J; the zero input would have two distinct outputs.
A10. Verify the rational ranks 9 and 15 by explicit row-reduction certificates; keep the inverse row operations.
A11. Define the generator closure algorithm on finite octad masks; prove its output contains the initial octad, is closed under J,T and has exactly the 759 octads.
A12. Deduce the orbit statement, without assuming a general transitivity theorem.

## Validation and publication boundaries

The corrected command-line program must check every requested view and every claimed norm; formalizing the input validator and its soundness is distinct from formalizing the abstract theorem. JSON parsing must reject duplicate residue entries, nonintegers, wrong frames and nonmatching columns. Mutation tests are reproducible software evidence, not theorem-prover acceptance.

No plan item proves positive ES occupancy for all primes, makes Schanuel unconditional, or identifies the Leech Mellin transform with Riemann xi. Those remain separate mathematical statements in the typed ledger.
