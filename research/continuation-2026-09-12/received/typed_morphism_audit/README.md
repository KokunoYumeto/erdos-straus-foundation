# ES–Fable–Leech: typed composition audit and short research notes

12 September 2026. This package contains a mathematical composition audit, exact coordinate repairs, three standalone three-page research drafts, a 49-arrow typed ledger, and reproducible execution records. It does not claim an ES or RH proof, historical priority, independent review, or a Lean build.

## Read first

`workbench_audit.pdf` is the 23-page integrated tranche. Its entrypoint is `workbench_audit.tex`; the bodies under `src/` can be integrated separately. `MORPHISMS.md` and `morphisms.json` state the source, target, domains, inverses, fibres, information losses and exact source locators for all 49 arrows.

The three research drafts are:

- `preprints/01_symmetry_complete_traces.pdf`: minimal full-symmetry trace completion, explicit all-octad inverse, and the single modulo-four integral obstruction.
- `preprints/02_octad_aligned_octonions.pdf`: a specified signed isometry from projective Golay to Wilson coordinates, aligned with the three octads, and the complete cubic correction.
- `preprints/03_shortest_trace_lifts.pdf`: the all-integer shortest three-trace inverse, now proved from eight norm-four seeds rather than a full minimal-shell census.

Each has a standalone TeX source, a one-page PDF card and a PNG card. `preprints/png/` also contains every preprint page rendered as PNG. The cards are reading/posting summaries; the complete proofs are the three-page PDFs.

## What changed mathematically

The nine time-traces are not a quotient for both symmetry generators. Their full linear orbit is rank24, represented by all759 octad traces. The inverse is explicit; integer compatible traces have exactly one cyclic mod4 obstruction.

The previously unspecified map between the two Leech models is now an octad-aligned signed permutation. A 37-generator check and equality of covolumes prove equality of the infinite lattices. Wilson already provided a MOG comparison; this is not claimed as the first model isometry.

The transported cubic is not determined by the three traces and is not invariant under every lattice isometry. Its full mixed correction is retained in the augmented Albert state. Explicit counterexamples identify these two failed compositions without rejecting the separate constructions.

Two output-validation weaknesses were reproduced in mutated copies of the old inverse utility: checking only the first of four requested triples, and trusting a shortest-norm label. The replacement checks all twelve readings, the full right inverse, and the actual shortest-norm formula. The old unmodified mathematics certificates pass.

## Run the new checks

Python 3.10+ and the standard library suffice for all new programs. No network or external package is required.

```console
python verify_audit.py --out regenerated/core
python -O verify_audit.py --out regenerated/core_optimized
python verify_shortest.py --out regenerated/eight_seed.json
python test_validation.py
python reconstruct_octad.py --self-test
python reconstruct_checked.py --trace 306 16218 1082101 --p 1201
python reconstruct_checked.py --four 1 2 3 2 3 1 3 2 1 1 4 1
```

`verify_audit.py` reconstructs the code and maps from explicit definitions, rather than importing the old checkers. Its full cubic test uses 2600 determining nodes, including signed pair sums. It also returns all three test ES markings through every one of the24 oriented/reversed face flags and the complete lattice/Albert route.

`reconstruct_octad.py --traces file.json` accepts759 integer traces in ascending octad-mask order, tests the complete linear image equations and mod4 syndrome, and reconstructs the unique numerator. The constant-one packet is a deliberate no-lift test. `--constant 4` returns numerator `(2,...,2)`.

`reconstruct_checked.py` treats every external certificate field as untrusted. It checks membership, all requested readouts, the exact frame, and the claimed norm. Its default certificate directory is the preserved predecessor directory under `inputs/leech_trace_inverse/certificates`.

## Replays and source fidelity

`inputs/` contains the eight available predecessor packages, with original TeX, code and data. The105 listed files retain their original hashes; generated bytecode is excluded from the release. `source_inventory.json` is the exact inventory. `run_replays.py` reproduces the18 original execution processes (two large arithmetic checks and eight normal/optimized pairs). Some inherited programs require SymPy; the new checker does not. Original assertion-using arithmetic programs reject optimized execution and were not misleadingly reported as optimized passes.

`replay_receipts.json` records actual commands, timings, source identities and normal/optimized comparisons. `execution_receipt.json` records the new tests. No count is treated as a probability or correctness grade. The scope is available local source packages, not every historical conversation or a full audit of every cited paper.

## Integrating into PolyClank

Use `workbench_manifest.json` as the integration entrypoint. It records each new result, exact artifacts, antecedent source relationships, repairs and unresolved conclusions. No existing GitHub branch, accepted claim ledger, publication or maintenance schedule was modified. The TeX modules and certificates are ready for a separately authorized integration step.

The theorem-level statements in the short notes are accompanied by complete proofs and fixed finite certificates. `source_reading.json` and `novelty_review.json` distinguish retrieved/inspected antecedents from search leads. A scoped search did not establish earlier exact versions of the selected coordinate statements, but no global priority claim is made. Do not rebrand classical Golay, Leech, first-Tits or Fable constructions as discoveries of this audit.

`lean_ready_plan.md` is an exact dependency specification, not compiled formal verification. The remaining ES task is still positive integral occupancy of the cubic for each prescribed prime; linear inverse and symmetry closure do not supply that existence assertion by themselves.

## Building the PDFs

Run `pdflatex` twice on each standalone preprint and on `workbench_audit.tex`. Standard TeX Live packages suffice. The card sources are in `preprints/*_card.tex`. Render PDFs with `pdftoppm -r 180 -png` to obtain posting images. Final PDFs and PNGs were rendered and visually inspected; no font files are redistributed.
