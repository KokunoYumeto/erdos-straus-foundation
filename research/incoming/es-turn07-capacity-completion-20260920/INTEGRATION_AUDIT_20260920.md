# Integration audit: exact cofactor capacity completion

## Received object and source preservation

The user supplied ES_Turns6_7_With_Capacity_Completion_20260920.zip and its
associated pasted continuation on 20 September 2026. Their exact bytes are
preserved under received/. The outer archive contains an unchanged copy of the
preceding Fabel bridge and one new current package,
ES_Turn7_Capacity_Completion_20260920.zip.

The received package had one source-packaging defect: core.tex opened the
three-case enumeration in the fixed-target capacity theorem but did not close
it. The received verification.json accordingly records a failed workbench
build even though its arithmetic replay succeeded, while the README named a
workbench PDF and publication receipt that were absent. The live source closes
that enumeration after the third case. Both the full workbench and short
preprint now compile twice without warnings. The received manifest is preserved
inside the archive; the current tree uses fresh hashes and receipts rather than
presenting that received manifest as current.

## Mathematical review

The integration retained five new results as stable claims SZ-20260920-040
through SZ-20260920-044:

1. the exact canonical/companion/finite classification of
   \(\mathcal A_t(j)\), including its inverse and every edge case;
2. the sharp finite boundary \(h\le t^2-3t+1\), equality family, eventual
   exact count and smaller returned grade;
3. unconditional same-prime middle returns on the three alpha lines
   \(t=1,2,3\) and nine beta lines \(t\mid36\), including nonsquare \(t\);
4. prime-realized sharpness for the unbounded family \(t=6+420z\);
5. for every fixed \(t\ge4\), infinitely many constructed hard-prime exterior
   states with empty complete middle capacity at the original grade.

The last item is typed only as a same-grade middle obstruction. Every prime in
its proof already has the constructed exterior solution, so it is not an
Erdős--Straus obstruction. The complete same-grade return itself refines
SZ-20260920-031 through \(U=W\) on alpha and \(U=j^2/W\) on beta. The inverse
E-gate correction at \(p=5209\) duplicates the already integrated correction
in SZ-20260920-030 and is not counted as a new result.

An independent second derivation checked the trichotomy, inverse, disjointness,
monotonic bound, equality conditions and eventual count without using the
packet verifier. A separate audit checked the CRT, reciprocity, Dirichlet
progressions, forced alpha/beta lines and same-grade obstruction construction.
These are internal mathematical rechecks, not external peer review.

## Reproduction

The following live commands passed:

    python verify.py --bound 3000 --target-bound 120 --j-bound 5000 --out certificates_replay
    python -O verify.py --bound 3000 --target-bound 120 --j-bound 5000 --out certificates_optimized_replay
    python check_independent.py --input certificates_replay --out certificates_replay/independent.json

The ordinary and optimized main runs each completed 1,161,828 checks. The
separate implementation completed 622,997 checks. Their retained mathematical
totals agree: 211 primes, 5,700 exterior states, 5,268 middle states,
1,877,004 original divisor vectors and 205 returned pairs. A separate audit
also extended the capacity replay to \(t\le250,\ j\le12000\), where both
implementations passed. That larger run is additional finite evidence, not a
replacement for the unbounded proofs.
