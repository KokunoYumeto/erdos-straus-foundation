# Split-box collision forcing and exact integral return

An additive continuation of the ES selector/character programme, based on main
`63f52c3d7162d2ba0c0d8187e4b1d5369f223ed9`. No universal ES theorem is claimed.

## Mathematics

- `preprint.tex` and `references.tex`: three-page standalone proof.
- `note.tex`, `split_box.tex`, `transport_details.tex`, and `references.tex`:
  five-page workbench version with complete state domains and affine inverses.
- `card.tex`: a one-page posting summary, not a replacement proof.
- `morphisms.json`: typed maps, inverse fibres, and information loss.
- `verification.json`: actual bounded replays, output hashes, and source scope.

For an actual prime-exponent box `B_e`, split `e=f+b` and pull the original
solution targets through `B_b`. Original target occupancy is equivalent to
occupancy of the expanded target set by `B_f`. Overlapping budgets are not
independent copies: the full addition fibres and nonconstant convolution
weights are retained. Apply the prior exact parity/character collision minimum
to the reduced box. Violating this minimum constructs the original integer
witness and all divisor/primitive coordinates.

At `p=1201,a=312,R=47`, the old test does not certify. Removing one power of
2 gives negative-cell mass 30, energy 46, and target-avoidance minimum 50.
The returned ordered witness is `(312,9608,46839)`, with M marking
`(R,u,h,r,s,lambda)=(47,1521,1,39,8,1)`. This is a stricter certificate in a
known shell, not new prime coverage or a chamber-positive-ray assertion.

For failures as well as successes, the partial residue differs from the
original arithmetic gate by a displayed unit. Every prime-power denominator
defect is therefore identical, and coordinate scaling gives a complete affine
conjugacy with an explicit inverse. This is not a defect-reducing cross-shell
move or an assertion about the source manuscript's global S6 conclusion.

## Reproduce

Python 3.9 or later, standard library only:

```sh
python verify.py --out generated
python -O verify.py --out generated_optimized
python verify_transport.py --out generated/transport.json
python -O verify_transport.py --out generated_optimized/transport.json
```

The core scan includes all 9,531 first-half shells at the 54 primes
`p=1 mod12, p<=1500`. The baseline certifies 240 shells; the union with the
specified one-prime-budget split tests certifies 438. Fourteen additions have
strict finite minima; 184 use infeasibility. The tautological retained-point
endpoint is excluded. No computational complexity advantage is claimed.

The second checker covers 12,042 labelled split states, including 11,658
failures, and explicit finite affine modules. General proofs and finite checks
remain separate. Normal and optimized JSON outputs agree. The distribution,
minimum allocations, all additional witnesses, and exact failure examples are
regenerated by these commands. The verification record supplies their hashes.

Build `note.tex`, `preprint.tex`, or `card.tex` with two `pdflatex` runs.
The local PDF/PNG outputs were inspected; source rather than binary publication
is included in this PR. `lean_plan.md` is a dependency plan, not a Lean build.
