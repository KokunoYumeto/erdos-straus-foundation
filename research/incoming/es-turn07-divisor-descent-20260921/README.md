# Original-divisor descent from rational Erdős–Straus trace sources

Status: verified source-descent and optimality results inside Turn 7. The
universal original-source existence problem remains open.

Read `preprint.pdf` first, then `workbench.pdf` and `core.tex` for the complete

## Exact result

Fix a prime `p = 1 mod 4`, an integer `p/4 < a < p/2`,
`R = 4a-p`, an original divisor word `u | a²`, and an E/M channel `c`. Put

```text
G_E = 4u+1,    G_M = p+4u,
d = R/gcd(R,G_c),    K(n) = product l^ceil(v_l(n)/2),    m = 4K(u).
```

The positive rational E/M tails have integral sum exactly when `R | G_c²`;
then their common reduced denominator is `d` and `d² | R`. Every positive
same-channel return that keeps `p,u` and replaces `R` by one of its divisors is
given by exactly one

```text
k | R,    d | k,    k = 1 mod m,
R' = R/k,    a' = (p+R')/4.
```

For a proper source (`d>1`) every such arrow strictly decreases `a`. After the
source is retained, its inverse is `k=R/R'`. Globally the domain is the set of
decorated arrows `(source,k)`, not the set of sources: one source can have
several targets. Above a full target `(p,a',R',u,c)`, the fibre is the exact
finite set

```text
1 <= k <= floor((p-1)/R'),    k = 1 mod m,
R'k | G_c²,    R'k does not divide G_c.
```

The workbench gives the resulting free-abelian pushforward, a basis for its
kernel by same-target arrow differences, a chosen right inverse, and the exact
direct-sum isomorphism retaining the lost fibre coordinates.

For square deletions write `R=delta t²` and `q0=K(d)`. The complete square
subdomain is

```text
k=q²,    q0 | q | t,    q² = 1 mod m.
```

The unit-square image modulo `m` is trivial exactly when `m | 24`, equivalently
when `u | 36`. Hence the universal fixed-word guarantee holds for exactly

```text
{1,2,3,4,6,9,12,18,36}.
```

For every other fixed word, the CRT/Dirichlet construction gives infinitely
many primes `p = 1 mod 840` carrying a proper M trace source for which every
same-word residual-divisor arrow fails. Its middle complement also fails. The
same primes have separate explicit E and M integer endpoint solutions, so this
is an optimality theorem for the descent system and not an Erdős–Straus
counterexample.

## Reproducibility and independent checks

Run the complete release replay from this directory:

```text
python run_release.py --directory results --pdf --render
python build_manifest.py
```

`run_release.py` executes the main verifier and the independently implemented
checker in both ordinary and optimized Python, requires byte-for-byte equality
of all mathematical JSON, compiles both TeX readers twice, and renders every
PDF page. The current bounded census uses all primes through 3,000 and retains
73,798 shells, 1,877,004 original divisor vectors, 5,274 proper trace sources,
1,864 returned proper-source arrows, 289 integral sources with nontrivial
returns, and 11,356 integral-source return arrows. These finite counts test the
implementation; the universal theorems are proved symbolically in `core.tex`.

  bounded challenge: 4,410 proper sources through `p<=5000,u<=200`, 17,635

`certificates/` and `verification.json` preserve the received certificate

## Scope

The module does not prove that every prime supplies a proper trace source, does
not prove Erdős–Straus, does not claim a counterexample, and does not report a
Lean build. The E-channel complement can become integral before a second-stage
descent: at `(p,a,R,u,c)=(37,16,27,2,E)`, the complement `u*=128` has `d*=1`
and only the identity factor `k=1`. The strict complement-descent statement is
therefore asserted only when the selected factor satisfies `k>1`; it is
automatic for proper M complements and not for arbitrary E complements.

Human sources and earlier programme proofs are linked at exact locators in
`references.tex` and `source_reading.json`. No historical-priority or novelty
claim is made.
