\begin{abstract}
We determine every same-word return obtained by replacing an original residual
by a divisor, starting from rational positive ES tails with integral first trace.
The word budget survives exactly at a specified residue class modulo
$4\prod_l l^{\lceil v_l(u)/2\rceil}$. A one-step integral return is guaranteed
for every such source precisely for the nine words dividing 36. Outside this
list we construct infinitely many hard-prime sources on which the entire
residual-divisor system, including the middle complement, fails. All source
multiplicities and denominator inverses are retained. This is a source-descent
and obstruction theorem, not a proof that every prime supplies an initial ES
state or a suitable rational trace source.
\end{abstract}
