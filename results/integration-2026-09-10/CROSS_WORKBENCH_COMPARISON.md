# Comparison with the existing workbenches

**10 September 2026.** This note refines the integration status of X1–X7 and the contribution opportunities in this PR. It does not certify the complete source corpus. A recovered draft, an integrated local reader, a public root source, and a frozen release are different versions until matched.

## Main conclusion

The CUE material should be maintained primarily in the [zeta workbench](https://github.com/KokunoYumeto/zeta-function-research-reader), and substantial portions are already there. The problem is partly a missing connection between public overviews, not missing mathematics. [Zeta PR #1](https://github.com/KokunoYumeto/zeta-function-research-reader/pull/1) supplies a structural reading map and records web-connected sessions as contributors. It does not duplicate the CUE proofs.

Inspected public roots: ES `9a3ddfe8b38a424f1ff0426201a1f4f6f9d2772f`; zeta `42d00e359b16d52ca71568ce5e3db5341949d929`; Yang–Mills/S6/fluid guide `8cfbd18f3e398c533e1acabfba98b4a29975000a`. The last was a programme-guide check, not a full review of its sources. ES source/ref checks and selected comparisons were performed through the GitHub connection. Hosted historical ZIP payloads remained unavailable; absence from those payloads is not established.

### X1 — Coefficient-derived M5(F107)

**Already written in an integrated local ES reader.** The supplied continuation archive (18), member `reader/erdos_straus_project_reader.tex`, includes the exact R_B, A_1 and A_6 matrices, determinants 8, 72, 40 and 15, and the 25-word determinant 32. See lines 59506–59695, labels **eq:BB107-rigidity-block**, **eq:BB107-score-volume-identity**, and **eq:BB107-full-matrix-algebra**. The same passage includes a proof and identifies its prior checker. X1 is a reconstructed check/exposition of this existing content, not a new discovery.

That local reader also includes **thm:BB-operation-length-tape-volume**, lines 59224–59321: a defined trajectory metric and scanned-cell complex give runtime as path length and scanned support as one-dimensional volume. Those constructions should not be lost. They are not a proved identity between Kolmogorov complexity and a separately given geometry. No public edition has been byte-matched to this local reader in this pass. The moving-frame cocycle in X1 is a scoped clarification; no current-source stationary-shift error was established.

### X2 — Descartes/Kocik quadratic pencil and rational limitation

### X3 — Support-sensitive semiring and universal maps

### X5 — Abstract C6 Fourier law and the modular-840 passage

**The discrepancy is localized to the named recovered passage. No defect in a current public proof has been established.** The computation 289³ = 169 modulo 840 is exact; it is not arithmetic -1. But an old passage making the opposite identification is not evidence that a later workbench still does so. The local ES reader's **eq:support-Fricke-principal-fibre** and nearby proof, lines 59717 and 59965, use the correct six-term orbit. That alone neither proves a full downstream repair nor identifies the same encoding.

Before proposing a correction to current mathematics, locate the exact current target/sign map and any statement depending on it. Preserve the abstract Fourier identity separately. The source-specific countercalculation is not a conclusion about a paper's publication history or about which argument the collaborator criticized.

### X6 — Finite Weyl phase-space basis

**Already fully covered, with a stronger explicit inverse, in the public zeta source.** [Literature foundations, lines 3293–3410](https://github.com/KokunoYumeto/zeta-function-research-reader/blob/42d00e359b16d52ca71568ce5e3db5341949d929/satellites/10_literature_foundations.tex#L3293-L3410), label **prop:finite-weyl-coordinate-isomorphism**, contains the full basis, twisted multiplication, trace inverse and traceless restriction. See the [CUE structural map](https://github.com/KokunoYumeto/zeta-function-research-reader/blob/polyclank/cue-crossworkbench-2026-09-10/CUE_RESEARCH_MAP.md).

### X7 — Neutral-state gap for a defined diagonal model

**Recovered finite-model result; exact counterpart in the public interacting workbench not established.** The [current Yang–Mills guide](https://github.com/KokunoYumeto/yang-mills-interacting-workbench/blob/8cfbd18f3e398c533e1acabfba98b4a29975000a/WORKBENCH.md) discusses specified regulated interacting systems, fixed-box comparisons and continuum questions. The word 'gap' does not identify those systems with S5's diagonal operator. X7 may be an independent model result; it is neither a correction to the current interacting theory nor proof of a transferred gap without an explicit operator map.
